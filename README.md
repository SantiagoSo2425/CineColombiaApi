# CineColombia API - Complete Implementation Guide

## Project Overview
This is a cinema management API built with .NET 6+ that handles:
- Movie catalog management (Pelicula)
- Theater and screen management (Teatro, Sala)
- Showtime scheduling (Funcion)
- Customer management (Cliente)
- Ticket sales (Ventum)
- Employee management (Empleado)
